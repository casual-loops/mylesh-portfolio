# The Observatory

A Next.js personal portfolio starter based on the approved Observatory direction.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Pages

- `/`: Home and original celestial motif
- `/work`: Work archive
- `/work/domain-doctor`, `/work/tapestree`, `/work/infrastructure-lab`: individual studies
- `/about`: Personal narrative
- `/experience`: Professional timeline
- `/cv`: CV summary

All pages share the navigation and contact footer.

## Edit content

- `content/site.ts`: profile, social links, project descriptions, project links
- `app/about/page.tsx`: About narrative
- `app/experience/page.tsx`: verified career timeline
- `app/cv/page.tsx`: CV summary
- `app/globals.css`: responsive design styles
- `public/images/observatory-planet.webp`: cropped from the original approved hero image supplied by the user

## Before publishing

1. Replace placeholder GitHub and LinkedIn URLs and add a contact email.
2. Verify employment history against your current resume.
3. Add genuine project screenshots and deployment/repository links.
4. Provide a verified resume PDF before enabling download.
5. Check accessibility and responsive behavior on target devices.

The source is a functional starter, not a claim that these content tasks are completed.
